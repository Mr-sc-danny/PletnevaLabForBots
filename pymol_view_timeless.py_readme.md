# pymol_view_timeless.py

Source: groups\caver_pymol\view_timeless\pymol_view_timeless.py

Purpose: CAVER-generated PyMOL snapshot-style viewer for a stable, frame-independent tunnel scene.
Usage: Run the script from PyMOL with its matching generated CAVER assets.
Inputs: Generated CAVER tunnel and structure files.
Calculation: Loads and styles a fixed tunnel visualization without trajectory animation.
Output: A stable CAVER scene suitable for a reference image or PyMOL session.

The script is organized into explicit input, calculation, and output sections where applicable.
