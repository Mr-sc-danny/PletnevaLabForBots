# pymol_view.py

Source: groups\caver_pymol\view\pymol_view.py

Purpose: CAVER-generated PyMOL static tunnel-view script for loading and styling a selected tunnel scene.
Usage: Run the script from PyMOL with the matching CAVER files and helper modules available.
Inputs: Generated CAVER tunnel files, structure files, and the matching PyMOL helper code.
Calculation: Executes generated PyMOL commands to load objects, apply colors, and configure the scene.
Output: A rendered static CAVER tunnel scene in PyMOL; save sessions or images from PyMOL as needed.

The script is organized into explicit input, calculation, and output sections where applicable.
